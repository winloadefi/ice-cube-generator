导入一个 MIDI 文件来生成 冰冰冰 老牧师音乐。
Import a MIDI File to Generate Chinese $Bing^3$ LaoMuShi Music.

Usage: 
```
python render.py [-h] [-m MIDI] [-s SAMPLE] [-o OUTPUT]
                 [-f {wav,mp3,m4a}] [-r ROOT_PITCH] [-b BPM] [-y] [-g GAIN]
                 [midi]
```

Requirements Install:
```
pip install mido numpy scipy soxr soundfile av
```
